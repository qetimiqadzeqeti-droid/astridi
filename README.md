### ინტერაქტიული საგანმანათლებლო ვებ-აპლიკაცია დაწყებითი კლასებისთვის

## 🌟 პროექტის შესახებ
ეს არის სპეციალურად **დაწყებითი კლასების (მე-2 და მე-3 კლასის, 7-9 წლის)** მოსწავლეებისთვის შექმნილი ფერადი, ინტერაქტიული და ბავშვზე ორიენტირებული საგანმანათლებლო ვებ-აპლიკაცია.

პროექტი ეძღვნება მსოფლიოში საყვარელი შვედი საბავშვო მწერლის — **ასტრიდ ლინდგრენის** შემოქმედებას და აერთიანებს ოთხ უკვდავ ნაწარმოებს:
1. 👧 **პეპი გრძელიწინდა**
2. 🚁 **სახურავის ბინადარი კარლსონი**
3. 👦 **ემილის თავგადასავალი**
4. 🌲 **ყაჩაღის ასული რონია**

ასევე მოიცავს მე-5 სპეციალურ საგანმანათლებლო მისიას:
5. 🏛️ **ექსკურსია საუნივერსიტეტო ბიბლიოთეკაში** — აკადემიურ სივრცეში ვიზიტისთვის მომზადება, ქცევის 4 ოქროს წესის გათავისება და საზეიმო სერტიფიკატის მიღება!

## 🎯 პედაგოგიური მიზნები და ინკლუზიურობა
- **ენობრივი ბარიერის დაძლევა:** აპლიკაცია განსაკუთრებულ ყურადღებას უთმობს ეთნიკური უმცირესობის წარმომადგენელ მოსწავლეებს (რომელთათვისაც ქართული მეორე ენაა):
  - ტექსტები მოკლეა (3-4 წინადადება), დაწერილია მარტივი, თბილი და გასაგები ქართულით.
  - ყველა საკვანძო სიტყვას ერთვის ვიზუალური ილუსტრაცია/ემოჯი.
  - **📚 პატარა სიტყვარი:** თითოეული ნაწარმოებისთვის შექმნილია ილუსტრირებული ლექსიკონის ბარათები (მაგ: ჭრელი წინდები, სადურგლო, ციხესიმაგრე, პროპელერი, გაზაფხულის ყიჟინა).
  - **🔊 ხმოვანი წაკითხვა და ვიზუალური კარაოკე:** ღილაკი „მომისმინე 🔊“ ტექსტს ხმამაღლა კითხულობს და სინქრონულად, წინადადებ-წინადადებ ანათებს ფონს, რაც ბავშვს სიტყვების ვიზუალურ აღქმასა და სწორი გამოთქმის გაგონებაში ეხმარება.
- **ღირებულებები და ეთიკა:**
  - **პეპი:** სამართლიანობა, სიკეთე, სუსტის დაცვა, განსხვავებულობის პატივისცემა.
  - **კარლსონი:** მეგობრობის ფასი, მარტოობის დაძლევა, გაზიარების სიხარული.
  - **ემილი:** ცნობისმოყვარეობა, შეცდომებზე სწავლა, მზრუნველობა და შრომისმოყვარეობა.
  - **რონია:** ბუნების სიყვარული, სიმამაცე, მშვიდობიანი თანაცხოვრება.
- **პოზიტიური უკუკავშირი:** შეცდომის დაშვებისას სისტემა არ სჯის ბავშვს — ეძლევა მეგობრული მინიშნება, ხოლო სწორ პასუხებზე ირთვება მხიარული ზანზალაკები, ვარსკვლავები და ტაშის ხმა (Web Audio API-ს დახმარებით, სრულიად ოფლაინ).

## 🎮 აპლიკაციის სტრუქტურა და ფუნქციონალი

### 1. მთავარი ეკრანი (Home)
- კლასის ამომრჩევი (**II ა** 🌟 / **II ბ** 🎈 / **III კლასი** 🚀) — სინქრონიზებულია სერტიფიკატთან.
- ვარსკვლავების საერთო მრიცხველი (0-დან 5 ვარსკვლავამდე).
- 4 დიდი ილუსტრირებული გმირის ბარათი + საუნივერსიტეტო ბიბლიოთეკის დიდი ბანერი.
- მასწავლებლის გზამკვლევის მოდალური ფანჯარა.

### 2. პერსონაჟების სივრცე (თითოეული წიგნისთვის)
- მოკლე, გასაგები ამბავი ვიზუალური ნიშნებით.
- **„მთავარი სიბრძნე“** (გამორჩეული ყუთი: რა გვასწავლა გმირმა).
- **„პატარა სიტყვარი“** — 4 ძირითადი ცნება ილუსტრაციითა და მარტივი ახსნით.
- **დავალება 1:** ნივთების შეცნობისა და დაკავშირების თამაში ცოცხალი მთვლელით (`🧺 შეგროვებული ნივთები: 0 / 4`).
- **დავალება 2:** სიკეთისა და ეთიკის 2-ვარიანტიანი ვიქტორინა.
- ორივე დავალების შესრულების შემდეგ იხსნება გმირის ოქროს ვარსკვლავი!

### 3. საუნივერსიტეტო ბიბლიოთეკის მისია
- საინტერესო შესავალი: რატომ მივდივართ საუნივერსიტეტო ბიბლიოთეკაში.
- **4 ოქროს წესი:**
  1. 🤫 ჩურჩულის წესი
  2. 🧼 სუფთა ხელების წესი
  3. 🚶 მშვიდი ნაბიჯის წესი
  4. 📖 წიგნის მოფრთხილების წესი
  *(თითოეული წესის ცალკე ან ერთად ხმამაღლა წაკითხვის ფუნქციით).*
- **ქცევის სიმულატორი:** 6 რეალური სიტუაცია („✅ კი, სწორია!“ / „❌ არა, არ შეიძლება!“).

### 4. ნორჩი მკითხველის საზეიმო სერტიფიკატი
- მოსწავლის სახელის, კლასის (II ა / II ბ / III კლასი), მასწავლებლის ხელმოწერისა და თარიღის რედაქტირება პირდაპირი გადახედვით (Live Preview).
- **„🎊 იზეიმე!“** ღილაკი — კონფეტის ფერადი წვიმა, საზეიმო ფანფარა და ტაშის ხმა.
- **„🖨️ სერტიფიკატის დაბეჭდვა / PDF“** — იბეჭდება იდეალურად A4 ფორმატში (ავტომატურად მალავს საიტის ღილაკებსა და მენიუს `@media print`-ით).
